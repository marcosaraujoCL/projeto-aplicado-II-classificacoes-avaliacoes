## 📌 Visão Geral do Projeto

A **Steam** (Valve Corporation) reúne diariamente milhares de análises dissertativas sobre jogos eletrônicos. Devido ao volume massivo dessas resenhas em linguagem natural, estúdios e publicadoras encontram dificuldades operacionais para ler, triar e classificar manualmente essas avaliações em tempo hábil.

O objetivo deste projeto é construir uma solução de **Ciência de Dados** baseada em **Processamento de Linguagem Natural (NLP)** e **Machine Learning Supervisionado** capaz de analisar o texto das avaliações dos jogadores e prever automaticamente a sua recomendação/sentimento (Positivo vs. Negativo), viabilizando a triagem rápida de problemas técnicos e críticas da comunidade.

---

## 📊 Base de Dados

* **Fonte:** *Steam Dataset 2025: Multi-Modal Gaming Analytics Platform* (repositório público).
* **Tipo de Dado:** Texto livre / Não estruturado (NLP).
* **Entrada ($X$):** Coluna `review` (análise textual escrita pelo usuário).
* **Alvo / Target ($Y$):** Coluna `voted_up` (`True` = Recomendado / Positivo; `False` = Não Recomendado / Negativo).
